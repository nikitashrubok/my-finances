# Мои финансы — GitHub Pages + Google Sheets

Этот проект переносит **интерфейс** на GitHub Pages, а данные читает и изменяет непосредственно через Google Sheets API с авторизацией Google OAuth. Google Apps Script и прежняя ссылка `/exec` для новой версии **не нужны**. Старую версию можно сохранить как резервную.

## 1. Проверь таблицу

Нужна существующая Google Таблица, лист с названием **Операции** и заголовками **строго в A1:F1**:

`ID операции | Расходы | Категория | Подкатегория | Дата | Комментарий`

**Перед первым запуском создай копию таблицы.** В этой версии удаление операции удаляет целую строку таблицы. Не размещай на листе «Операции» дополнительные независимые данные вне A:F, поскольку удаление строки сдвинет и их.

ID таблицы находится в её URL между `/d/` и `/edit`. Это НЕ идентификатор развертывания Apps Script.

## 2. Google Cloud

1. Открой https://console.cloud.google.com/ и создай или выбери проект.
2. В **APIs & Services → Library** включи **Google Sheets API**.
3. В **Google Auth Platform / OAuth consent screen** настрой приложение (обычно тип External). При режиме **Testing** добавь свой Google-аккаунт в **Test users**. Учти, что в Testing могут действовать ограничения на сроки жизни согласия и токенов; в режиме Production для чувствительных областей доступа Google может потребовать проверку приложения.
4. Создай **OAuth client ID** типа **Web application**.
5. В **Authorized JavaScript origins** добавь ТОЧНЫЙ origin GitHub Pages: `https://USERNAME.github.io` (без пути репозитория, без завершающего `/`). Если используешь собственный домен, добавь и его origin.
6. Скопируй **Client ID** (строка вида `...apps.googleusercontent.com`). Client secret для этой схемы НЕ нужен и в GitHub его публиковать нельзя.

Для авторизации используется Google Identity Services и область доступа `https://www.googleapis.com/auth/spreadsheets`. Эта область предоставляет приложению широкий доступ к таблицам, доступным вошедшему пользователю. Используй отдельный Google-аккаунт или отдельный проект, если это важно для твоей модели безопасности. **GitHub Pages публичен:** не публикуй там конфиденциальные данные, access token или client secret. OAuth Client ID не является секретом.

## 3. Заполни настройки

В начале `app.js` замени:

```js
CLIENT_ID: 'ВСТАВЬ_OAUTH_CLIENT_ID.apps.googleusercontent.com',
SPREADSHEET_ID: 'ВСТАВЬ_ID_GOOGLE_ТАБЛИЦЫ',
SHEET_NAME: 'Операции',
```

на свои данные. Твой прежний URL `script.google.com/macros/s/.../exec` здесь **не используется**.

## 4. Публикация GitHub Pages

1. Создай репозиторий на GitHub, например `moi-finansy`.
2. Загрузи **содержимое** этой папки в корень репозитория: `index.html`, `app.js`, `styles.css`, `manifest.webmanifest` и папку `icons`.
3. В **Settings → Pages → Build and deployment** выбери **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажми Save.
4. Открой адрес `https://USERNAME.github.io/moi-finansy/`.
5. Нажми **«Войти в Google»** и выдай доступ к таблицам. Google-аккаунт должен иметь доступ к нужной таблице на редактирование.

## 5. Иконка на iPhone

- В `index.html` уже есть `<link rel="apple-touch-icon" sizes="180x180" href="./icons/icon-180.png">`.
- В `manifest.webmanifest` уже указаны иконки 192×192 и 512×512 и `display: standalone`.
- В Safari на iPhone открой **именно GitHub Pages**, а не старый URL Apps Script.
- Нажми **Поделиться → На экран «Домой»**; при наличии переключателя включи **«Открывать как веб-приложение»**.
- Если ранее был ярлык с другой иконкой, удали его и создай заново: iOS может кэшировать значки.

## 6. Ограничения и особенности

- **Важно для iOS:** Google OAuth в режиме всплывающего окна может не работать в standalone-веб-приложении из-за ограничений авторизации/всплывающих окон. Сначала проверь вход в Safari. Если в режиме с главного экрана вход не открывается, используй Safari или реализуй отдельную серверную OAuth-схему. Данный проект не обещает безусловную работу OAuth в iOS standalone.
- Google Identity Services не хранит здесь токен между запусками: после перезапуска может понадобиться снова нажать «Войти в Google».
- Без интернета чтение и запись операций не работают.
- Не редактируй одновременно одну и ту же операцию из нескольких устройств: номера строк могут меняться. Перед изменением и удалением приложение перечитывает лист, но не обеспечивает транзакционную блокировку.
- В приложении дата новых операций сохраняется строкой `YYYY-MM-DD`; старые значения в виде `ДД.ММ.ГГГГ` также распознаются.
- Проект использует Chart.js и Google Fonts из внешних CDN.
- Файлы `icons/icon-*.png` созданы из изображения, предоставленного пользователем. Убедись, что у тебя есть необходимые права на использование изображения.
